# رسائل وبصمات تحت راية الاتحاد

منصة تفاعلية لرسائل المدارس الحكومية في مدينة العين — صفحة واحدة تعمل في أي متصفح بدون تسجيل دخول.

- `index.html` — الموقع كاملًا (خريطة العين، البحث والفلاتر، بطاقات المدارس، نموذج الرسالة مع حفظ تلقائي).
- `config.js` — رابط استقبال المشاركات (Google Sheets). انظري `apps-script/README.md`.
- `assets/img/` — ضعي هنا الصور الزخرفية المولّدة من `image-prompts.md` (scenery-top.png, scenery-bottom.png, map-parchment.png, frame-corner.png).

**الشعار:** «كل مدرسة حكاية… وكل رسالة بصمة وطن» · «الإمارات… وطن يجمعنا»
